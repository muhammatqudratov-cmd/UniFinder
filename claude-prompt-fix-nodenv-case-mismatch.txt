Context: this is a pre-deploy bug fix for the backend (NestJS monorepo, apps: unifinder-api, unifinder-batch). A full audit found exactly one certain, reproducible logic bug, present identically in two files. No other code change is included in this prompt — this is the only fix, and it does not alter any business logic beyond correcting a string-case typo.

The bug: in both `database.module.ts` files, the MongoDB connection string is chosen by comparing `process.env.NODE_ENV` against the UPPERCASE literal `'PRODUCTION'`:

```ts
uri: process.env.NODE_ENV === 'PRODUCTION' ? process.env.MONGO_PROD : process.env.MONGO_DEV,
```

...but two lines below, in the same file, the connection-success log message compares the SAME variable against the lowercase literal `'production'`:

```ts
console.log(`MongoDB connected succesfully to ${process.env.NODE_ENV === 'production' ? 'production ' : 'development'} db`);
```

`NODE_ENV` is set to lowercase `production` by virtually every Node.js hosting platform and tool (Render, Railway, Heroku, PM2, Docker `ENV NODE_ENV=production`, etc.) and is never conventionally set to uppercase `PRODUCTION`. Because of this case mismatch, the `uri:` line will NEVER match `'PRODUCTION'` in real-world deployments, so the app will always connect to `MONGO_DEV` even when correctly deployed with `NODE_ENV=production` — while the log line right below it will correctly print "production db", misleadingly suggesting the production database is in use when it is not. Right now `MONGO_DEV` and `MONGO_PROD` happen to hold the same connection string in `.env`, so this bug is currently invisible — but it will silently route to the wrong database the moment those two values are ever set differently (e.g. a separate production cluster).

This prompt fixes the case mismatch by making both comparisons consistently lowercase (`'production'`), matching standard Node.js convention and the working log-line comparison already in the same file.

=====================================================================
FILE 1 — apps/unifinder-api/src/database/database.module.ts
=====================================================================

Find:
```ts
				uri: process.env.NODE_ENV === 'PRODUCTION' ? process.env.MONGO_PROD : process.env.MONGO_DEV,
```
